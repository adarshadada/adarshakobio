Edit every page of the site and save it straight to your GitHub repo.

How to get a token
  1. On GitHub open Settings, Developer settings, Fine-grained tokens, then Generate new token.
  2. Under Repository access choose Only select repositories and pick this site’s repo.
  3. Under Permissions set Contents to Read and write.
  4. Generate it and paste it above. The token stays in this browser and is only sent to GitHub.

Anyone can open this page, but nobody can change the site without a token. Do not share yours. “Edit without GitHub” lets you edit text here and download the result, but it cannot upload photos.
